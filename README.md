## 📌 Competition Overview
- **Goal:** Predict individual likelihood of purchasing an Electric Vehicle (`Will_Buy_EV`).
- **Metric:** ROC-AUC.
- **Dataset Scale:** 
  - **Train:** ~668,665 records
  - **Test:** ~286,571 records
  - **Features:** 13 raw tabular attributes covering demographic, infrastructure, and vehicle usage signals.
- **Competition Field:** 3,500+ global data scientists and machine learning practitioners.

---

## 🏆 Key Architectural Innovations & Breakthroughs

### 1. Reverse-Engineering the Synthetic Data Generator
- **The GPT-2 Tokenizer Fingerprint:** Tabular generative models frequently emit tokenization artifacts. By decomposing `Annual_Income_USD` into GPT-2 BPE token boundaries (e.g. ` 9|28|87`, ` 17|05|37`), individual linear models achieved **AUC > 0.717** on income alone—substantially higher than traditional continuous splits or decimal brackets.
- **Micro-Scale Decimal Digit Decomposition:** Decomposing every numeric attribute across 8 powers of 10 ($10^{-4}$ to $10^{3}$) enabled shallow decision trees to detect non-linear precision and rounding artifacts in a single split.

### 2. Multi-Resolution Feature Engineering
- **Macro Level:** Global relative frequencies and Bayesian out-of-fold target encodings with empirical shrinkage.
- **Meso Level:** 1280-quantile neighbor target encoding (`neighbor_qte`) smoothed across adjacent bins via a 3-tap Gaussian kernel convolution ($\sigma = 0.8$).
- **Micro Level:** Decimal place and modulo extractions across continuous variables.

### 3. Logit Margin-Boosted Architecture (GLM ➔ GBDT)
Rather than training standard tree models directly on raw targets, the log-odds (logits) of a generator-aware Ridge Logistic Regression were supplied as the `init_score` (margin) to LightGBM and XGBoost. This anchored trees on the global linear structure while letting splits focus purely on non-linear residual signals.

### 4. Leak-Free Nested Coordinate Ascent Rank Stacking
- Standard blending and soft-voting often overfit public leaderboards and fail on disparate model calibration curves.
- Predictions were converted to uniform percentile ranks and optimized via **coordinate ascent on Mann-Whitney AUC inside a 5-fold nested cross-validation loop**.
- Achieved positive generalization gains across every fold (+0.00012 to +0.00018 AUC over the strongest single model), pushing the combined out-of-fold benchmark past **~0.9466+ AUC**.

### 5. Deterministic Boundary Rules Post-Processing
Isolated strict deterministic separation boundaries generated by the underlying data generator:
- `Annual_Income_USD >= $170,537`: 100% deterministic buyers (393/393).
- `$31,004 <= Annual_Income_USD <= $41,970`: 0% buyers (0/1,257).
- `Daily_Commute_km >= 83`: 0% buyers (0/186).
- `Annual_Income_USD == $30,000` & No Subsidy & (High Anxiety or Concern=1): 0% buyers (0/7,157).

## 🚀 Getting Started

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/satyam-257/Predict-ELectirc_vehicle-purchase.git
cd Predict-ELectirc_vehicle-purchase
pip install -r requirements.txt
```

### 2. Dataset Setup
Download the competition dataset from [Kaggle Playground Series s6e9](https://www.kaggle.com/competitions/playground-series-s6e9) and place it under `data/`:
```text
data/
├── train.csv
├── test.csv
└── sample_submission.csv
```

### 3. Model Training & Pipeline Execution
Train the individual backbone models:
```bash
# 1. Train GLM Margin LightGBM
python train_glm_margin_gbdt.py

# 2. Train Multi-Resolution LightGBM
python train_zoom_zoom_lgbm.py

# 3. Train Generator-Basis XGBoost
python train_heuljax_xgb.py
```

### 4. Ensembling & Boundary Post-Processing
Generate the nested rank-stacked submission:
```bash
python ensemble_frontier_v10.py
```
